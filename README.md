# Sistema de Gestão de Stocks

Este projeto está a ser desenvolvido como parte prática de um módulo do CET de Sistemas de Informação.

## Tecnologias Planeadas / Em Desenvolvimento:
- **Back-End:** PHP
- **Base de Dados:** MySQL
- **Front-End:** HTML5, CSS3

## Funcionalidades Próximas:
- [ ] Registo e autenticação de utilizadores.
- [ ] Registo das categorias de produtos e ferramentas.
- [ ] Controlo de entradas e saídas de produtos.
- [ ] Listagem de alertas para produtos com stock baixo e vencimentos próximos.
- [ ] Exportação de relatórios (PDF/Excel).
